# 2. Security Incident Report: Brute Force Attack

**Skills:** incident documentation · DNS · HTTP · brute-force mitigation

## Protocols involved
- **DNS** (Domain Name System)
- **HTTP** (Hypertext Transfer Protocol)

## Incident summary
A threat actor ran a successful brute-force password attack against the administrative portal of `yummyrecipesforme.com`. The attacker exploited weak, default credentials to gain full control and then changed the admin password, locking out authorized staff.

## Recommended remediation
- Monitor login attempts
- Require strong passwords
- Implement an account lockout policy and login attempt limits
